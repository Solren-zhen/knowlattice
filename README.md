# 晶格 · KnowLattice

一款为医学生而生、也适合所有学习者的**本地优先个人知识笔记软件**。当前为**纯 Web 版**（存储走 IndexedDB，后续套 Tauri 壳零改动）。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
```

其他命令：`npm run build`（类型检查 + 打包）、`npm run lint`（oxlint）、`npm run preview`（预览构建产物）。

## 已实现功能

### 笔记核心（M1~M3）

- 三栏主界面：章节树 | CodeMirror 编辑器 | 实时预览
- 新建笔记自动填 frontmatter 模板（aliases/tags/chapter/source/created）
- 「属性: 内容」键值对在预览中自动加粗
- Ctrl+S 保存；删除笔记；图片粘贴保存到 `_attachments/`
- `[[双链]]`：输入自动补全（文件名/标题/alias），点击跳转，反链面板
- Ctrl+K 快速搜索：标题模糊匹配 + 全文搜索（MiniSearch + 中文 bigram）+ 最近打开排序

### 3D 解剖图谱（M5）

- 基于 [Anatria-3D](https://github.com/Nurkan1/Anatria-3D)（Apache-2.0 代码 + CC BY-SA 4.0 模型，HuBMAP 人类参考图谱源）
- 12 系统 × 3478 结构，Draco 压缩 GLB 按系统懒加载，three.js 原生渲染
- 结构中英文对照搜索；点击结构 ↔ 笔记双向打通（无笔记时一键创建并自动填 chapter）
- **点结构即看笔记（卡片）**：单击 3D 结构（或右侧结构列表）后，在光标旁浮现一张**结构笔记卡片**，直接把该结构对应笔记的正文摊开——不用先跳进编辑器。卡片位置贴着点击点、贴边自动翻面并夹紧在 3D 舞台内；笔记不存在时卡片里给一键创建入口；卡片里的 `[[双链]]` 照样可点。Esc 先关卡片、再关整个图谱
- 合规：保留 NOTICE 与 manifest 内 attribution 展示

### 间隔复习 SRS（M6）

- 一张卡 = 一个知识点：笔记按 `##`/`###` 小节切卡（正面 = 小节标题 + 本节属性键，背面 = 该小节正文）；没有小节的短笔记仍整篇一张卡
- FSRS（ts-fsrs）遗忘曲线调度，每日复习队列；口诀卡片优先提示口诀

### 真题锚点 + 错题本（M7）

- 笔记 frontmatter `exam:` 字段标记历年真题
- 错题归档到章节，薄弱点直达对应原子笔记

### 番茄工作台（M10）

一个整页面板装三个模块，顶部标签切换，**计时条常驻**——切到哪一页都看得到还剩多久：

- **专注**：番茄钟（默认 25 / 5 / 15 分钟，每 4 个专注后长休息；各段时长与「自动开始下一阶段」都能改）。计时环 + 开始/暂停/重置/跳过；`空格` 开始暂停、`S` 跳过
  - **与待办联动**：专注前选一条待办，每完成一个番茄它 **+1 番茄数**（列表行上显示 `🍅 N`，行上的「专注」按钮一键把某条设为本次专注对象并切过去）——投入是记出来的，不是估出来的
  - 计时**按真实时间戳算**，不靠定时器累加：标签页被挂起、系统休眠、渲染卡顿都不会漂移（25 分钟不会变成 24 分 40 秒）
  - 关掉面板也在走，重开按真实时间接上；补记的时间点算**真正跑完那一刻**，不是「你重开面板那一刻」（跨零点也记在昨天）
  - 跳过专注**不记**番茄——没做完就是没做完
- **待办**：整页三栏，默认打开的就是这一页（详见下一节）
- **统计**：今日/累计番茄与专注分钟、近 7 天专注趋势柱状图、待办完成率、**学习打卡热力图**（近 12 周，GitHub 风格，周一为行首）
  - 这里**不做**第二套手动「习惯打卡」：复习评卡 / 题库作答已经在记打卡（`core/stats.ts`），热力图直接画那份真实学习记录——两套并行的「连续天数」迟早对不上
- 番茄记录随**整包备份**走（备份 v5），换设备不丢

### 待办模块（M9）

- **整页三栏**：左栏智能列表（今天 / 明天之前 / 本周内 / 已逾期 / 全部未完成 / 已完成 / 全部，都带计数）+ 按关联笔记分组；中栏列表与批量操作；右栏选中项详情（没选中时是进度、近 7 天完成曲线、连续完成天数）
- 一句话记一条：`复习呼吸系统 @明天 !高 #呼吸系统 *每周`——输入时实时显示**认出来的标记**，没认出来的原样留在正文里（不会吞掉你写的内容）
  - `@` 日期：`@今天 @明天 @后天 @昨天 @周一…@周日 @本周 @下周 @9-25 @2026-09-25 @+3`
  - `!` 优先级：`!高/!中/!低` 或 `!1/!2/!3`；`#` 关联笔记（按笔记名精确匹配，不区分大小写，可从下拉里选）
  - `*` 重复：`*每天 *工作日 *每周 *每两周 *每月`——工作日自动跳过周末；每月遇短月夹到月末，不会溢出到下下月
- **笔记里的任务也能看见、能勾**：笔记里写的 `- [ ] 背氧解离曲线 📅 2026-09-25 ⏫` 会出现在左栏「笔记里的任务」下，勾一下**直接写回笔记**（`[ ]` ⇄ `[x]`，完成时补 `✅ 日期`），约定对齐 Obsidian Tasks
  - 写回前会核对那一行还是不是同一个任务：笔记在别处被改过就不动它，提示手动勾——宁可漏勾一次，不可写坏笔记
- 批量：`Ctrl/⌘+点击`多选、`Shift+点击`范围选，或按 `m`；批量完成 / 取消完成 / 改今天 / 改明天 / 清除日期 / 删除（重复任务批量完成照样顺延下一条）
- 删除有**撤销**（8 秒内点一下整份恢复）；逾期一键「顺延到今天」；分组可折叠；排序有手动 / 到期 / 优先级 / 创建时间 / 标题，分组可按到期或按笔记——排序与分组关掉再打开还记得
- 键盘：`n` 新建 · `↑↓`/`j k` 选 · `x`/空格 勾选 · `Enter` 编辑 · `Delete` 删除 · `e` 跳详情 · `1 2 3` 设优先级 · `0` 清除 · `m` 多选；双击文字就地编辑（回车/失焦保存、Esc 放弃、清空即删除）
  - 面板底部**不列快捷键**了（那是自说自话的装饰），改成解释**短语法**：符号 → 含义 → 示例，示例点一下就插进输入框。快捷键照旧可用，只是不再占版面
- 列表行上的关联笔记一点就跳过去；「全部完成」不会覆盖已经完成那条的完成时间

### 知识图谱（三期）

- 类 Obsidian 全库双链网络图：笔记为节点、`[[双链]]` 为边，canvas 力导向布局
- 拖拽节点重新布局、滚轮缩放、空白平移；悬停高亮邻域，单击节点直达笔记
- 节点颜色按一级章节区分，节点大小 = 连接度

### 题库练习（三期）

- 导入 JSON 题库（文件或粘贴，兼容中英文字段名，格式见「题库练习」面板内说明）
- 随机组卷逐题作答：选择题点击判分，简答题显示答案后自判
- **选项批注**：答案出现后，每个选项右侧多一支铅笔——点开写下「这个选项为什么对 / 为什么错」，下次一眼看到。批注按选项下标对齐存进题库（`optionNotes`），随备份一起导出；重练同一题、或重新导入同名题库（按「题干 + 选项」接回）都还在
- 答错且题目标注了关联笔记时，自动收录进错题本；结果页错题可直达笔记
- 项目根目录附 `样例题库.json` 可直接导入体验

#### 外部题库批量转换（`scripts/qbank-to-vault.mjs`）

绿皮书、医考帮那类「一个章节一个 markdown」的题库，用一条命令转成上面两种导入格式：

```bash
node scripts/qbank-to-vault.mjs [--out <目录>]
```

产出三样：① `knowlattice-导入-<源>题库.json` 走**数据管理 → 导入备份**（无损，题目原文一字不改，落成 `题库/<源>/<学科>/<章节>.md`，带 frontmatter 便于按标签筛）；② `knowlattice-题库/<源>·<学科>.json` 走**题库练习 → 导入题库文件**（解析成题目，带章节标签与解析）；③ `knowlattice-题库-INDEX.md` 索引，写明每个文件多少题、多大、有哪些数据坑。

两个坑写在脚本注释里，也是踩出来的：选项**不能按行扫**（源里常一行塞 2–3 个，还有连写无空格的 `…用量B.妊娠期…`），改成扫候选字母再取「从 A 起连续递增」的最长链；标记可能被加粗（`**【A1】题干：**`），行首要容错。

题库存的是 `localStorage`（约 5 MB），所以脚本按**最终 JSON 体积**装箱，每份 ≤ 0.9 MB——按原始对象估大小会低估一倍，上限就形同虚设。

### 新手引导（M8 · 医学生零门槛）

- 新建笔记向导：选「概念/疾病/机制/检查/口诀/空白」类型，自动生成对应骨架填空
- 编辑器格式工具栏：撤销 / 重做 / 加粗 / 列表 / 缩进 / 双链 / 口诀按钮，悬停查看快捷键
- 行内格式快捷键（与工具栏按钮同一段实现）：**Alt+A 加粗**、**Alt+S 高亮**、**Alt+Z 斜体**、**Alt+X 插入双链**（都是两个键，且四个键都落在左手基准位，一只手就能按）；加粗/高亮再按一次即取消，空选区按下会插入占位文字并选中它（直接打字即替换）。双链插入后自动弹出笔记名候选（含 alias），回车即可连上。撤销/重做仍为 Ctrl/⌘+Z、Ctrl+Shift+Z、Ctrl+Y
- 所见即所得混合预览：光标所在行显示源码，其余行实时渲染排版（标题/列表/引用/加粗/双链等），眼睛按钮切换
- 首次启动自动创建「三分钟上手」示例笔记；空状态三步教学

### AI 助手（M8）

- 侧栏内嵌免费网页 AI 问答（Kimi / 智谱清言 / 通义千问 / 元宝 可内嵌，DeepSeek 需新窗口），避免学习时来回切屏

### 智能草稿（M9）

- 粘贴讲义段落或导入 PDF（pdf.js 提取文字），一键生成原子笔记骨架（识别定义/来源/机制/作用/分类/鉴别等语义）
- **自动识别序号序列**（1、/一、/A./①），教材编号结构原样保留为有序列表
- 人工审核修改后入库，自动按章节归类

### PDF 讲义对照视图（M9）

- 左侧 react-pdf-viewer 渲染 PDF 原版（可选中文本层/缩放/翻页/搜索），上次使用的 PDF 自动恢复；Word(.docx) 由 docx-preview 还原排版
- 划选重点 → 右侧生成**原文摘录**（自动清理 PDF 中文排版空格，不再拆分为“作用 / 要点 / 内容”）
- 可新建笔记，或选择已有目标笔记连续追加多段摘录；保存后自动保留目标笔记，避免重复写入上一段
- **摘录历史**：划选记录自动留存，可回填编辑、标记已入库状态
- 示例文件 `public/sample-lecture.pdf` 可直接体验完整流程

### 数据管理

- 一键备份/恢复（.json，含 SRS 进度/题库/错题/**待办/打卡/卡片自定义**；v4 格式，v3 及更早备份兼容导入，旧版 dataURL 附件自动迁移为 Blob）
  - 待办与打卡是 v3 补上的：这两样此前只活在 `localStorage` 里（`knowlattice-todos` / `knowlattice-days`），备份完全覆盖不到——换设备、重装、清浏览器数据即永久丢失，且界面不会有任何提示
  - 卡片自定义（正面/背面覆盖、删卡标记）是 v4 补上的：它刻意和笔记内容分开放（`knowlattice-card-edits`），所以备份必须单独带上——否则换设备后「我改过的问题/答案」全部回到笔记原文，而笔记文件看起来完好无损，用户根本不会意识到丢了东西
  - **已知边界**：二进制图片附件不进 .json 备份（新附件库独立存放，不并入 JSON 以免体积爆炸）。要连图片一起搬走请用下面的「导出为 md 文件夹(.zip)」，它带真实图片原文件
- **导出为 md 文件夹(.zip)**：真实 Markdown 目录结构（含 [[双链]]/frontmatter 与图片附件原文件），可直接用 Obsidian/记事本打开——数据永不锁定
- 存储适配器抽象：`storage/web.ts`（IndexedDB：笔记 files store + 附件 attachments store）↔ `storage/tauri.ts`（M4 接入）

### 最近更新（2026-09-21）

- **离线包支持 macOS / Linux**。此前只有 `Start-KnowLattice.bat`（Windows + PowerShell），Mac 同学拿到包打不开——分享出去等于只发了一半。现在多一套 `start-knowlattice.command` + `server.py`（Python 3 标准库，零依赖），行为与 `server.ps1` 逐条对齐：只监听 127.0.0.1、同一张 MIME 表（`.wasm` 必须是 `application/wasm`，否则浏览器拒绝流式编译）、无扩展名路径回退 `index.html`、「已在运行就打开它」的端口复用策略（笔记按 origin 隔离，换端口 = 空库）、浏览器断连不把服务搞死。
  - **验收是真跑的**：用免安装 CPython 3.12 起服务，**裸 socket 发原始请求**逐条核对——`.wasm` 返回 `application/wasm`、`../` 与 `%2e%2e%2f` 与 `..%2f..%2f` 三种穿越全 403、无扩展名路由 200 回 index.html、404 是纯文本、HEAD 有 Content-Length 无 body、**连上就断 20 次后服务照常应答**；端口策略两条路都验了（已运行 → 打开旧实例并退出 0；被别的程序占用 → 换端口 + 黄色警告，话术与 PS1 一致）。
  - **zip 里的可执行位**：macOS 的访达靠 zip 记录里的 Unix 权限位决定 `.command` 能不能双击运行，而 Windows 文件系统没有这个位（bsdtar 写出来是 0644，同学双击只会看到「没有权限」）。pack.mjs 压缩后只改中央目录那两条记录（不动压缩数据、不动 CRC），并用裸字节解析复核 `version-made-by=0x31e` + 模式 `755`。
  - **漂移守卫**：新增 `src/core/__tests__/packServers.test.ts`（8 项）逐项对账两套实现的 MIME 表、回环监听、SPA 回退、端口策略，以及 pack.mjs 是否把四个启动文件都装进包——只改一边会让某个平台静默失效，这条测试就是防这个。
- **外部题库批量导入**。绿皮书（976 个 md）与医考帮（1137 个 md）两套 markdown 题库转成晶格能直接吃的 JSON：笔记形式 **976 + 1137 篇**（无损，走「数据管理 → 导入备份」），题库形式 **111,548 道题**（走「题库练习 → 导入题库文件」，127 份、每份 ≤ 0.9 MB）。转换器 `scripts/qbank-to-vault.mjs` 常驻仓库，源更新了重跑一条命令即可。
  - **解析踩的两个坑**（都是数据里长出来的，不是想出来的）：① 选项**不能按行扫**——源里常一行塞 2–3 个选项，还有连写无空格的 `…减少胰岛素用量B.妊娠期对胰岛素敏感性降低…`，改成「扫全部候选字母 → 取从 A 起连续递增的最长链」；② 标记会被加粗（`**【A1】题干：**`，神经病学整个学科都是），行首要容错。改完绿皮书的**漏题从 1330 降到 143**（0.26%）。
  - **验收用晶格自己的导入器**，不用我自己再解析一遍：`normalizeQuestions` 吃下全部 127 份题库、**111,548 题零丢失**；40 MB / 1137 篇的备份走真实 `importBackup` 整包导入，**逐篇内容比对全部一致**（`{ok:1137, failed:0}`）。
  - **源数据本身的坑照实标注**：绿皮书 B1（共用选项）题导出时丢了 A 选项、只剩 B–E，这类题一律降级成自判题（题干带选项 + 正确答案），**不做字母重排**——重排会让字母和原书对不上，宁可自判也不给错答案；多选题（X 型）同理（晶格的答案是单选下标，装不下多选）。两条都写进 `knowlattice-题库-INDEX.md`。
  - 题库存 `localStorage`（约 5 MB），所以按**最终 JSON 体积**装箱：最初按原始对象估大小，上限形同虚设（最大一份 2.6 MB），改成序列化后再量，现在最大 876 KB。

- **目录树里能删「一整篇」笔记了**。此前目录里只有「批量删除」：想删单独一篇，要么先进批量模式勾一篇再删，要么先把它打开、再从编辑器头部那个只有图标没有提示的垃圾桶删——用户反馈「没找到独立删除的入口」。现在每行笔记右侧常驻一个低对比垃圾桶（悬停/聚焦变红），并且**在行上点右键**会弹出「打开笔记 / 删除整篇笔记」菜单（样式与编辑器右键菜单同源）；编辑器头部那个垃圾桶也补上了文字提示。两个实现细节：①垃圾桶是行的**兄弟**节点而不是子节点——行本身是 `role="button"`，里面再套一个 button 属于嵌套可交互元素，屏幕阅读器会读乱；②右键菜单接进全局 Esc 栈（一次只退一层），点外面 / 窗口失焦 / 缩放 / 目录滚动都会关，且判断「点在菜单自己身上」不算点外面（否则 `pointerdown` 先把菜单关掉、随后的 `click` 落在已卸载的按钮上）。新增 9 项 DOM 测试，含「点垃圾桶不会顺手打开笔记」和「批量模式下右键不出菜单」。

- **错题本清不掉的那条记录**：`loadMistakes()` 返回模块级缓存本身、`clearMistake` 就地删除后返回同一引用，于是 `setMistakes(clearMistake(path))` 拿到同一对象被 React 的 `Object.is` 直接 bail out——记录从 `localStorage` 删了，但行还在、顶部计数不变、热力条不变。三个写函数现在一律返回新对象（`loadMistakes` 返回浅拷贝），并补了 4 项引用语义回归测试。
- **Ctrl+K 高亮项自动滚入视口**：上下键移出可视区后高亮条看不见，此时回车会打开一篇用户根本没看到的笔记。

### 最近更新（2026-09-19）

- **行内格式快捷键改到左手基准位**：原 `Ctrl/⌘+B` 加粗 / `Ctrl/⌘+H` 高亮 / `Ctrl/⌘+I` 斜体 / `Alt+K` 双链四键分散在三处，大键盘上 `Ctrl` 在左、字母在右，必须两只手。现在统一为 **Alt+A 加粗 / Alt+S 高亮 / Alt+Z 斜体 / Alt+X 双链**：A、S 就是左手基准键，Z、X 在其正下方一行，拇指按住左 Alt、其余手指原地按，一只手完成。选键前逐个查过 Chrome 官方快捷键表：`Ctrl+A/S/F` 是全选/保存/查找，`Alt+D` 是地址栏、`Ctrl+数字` 是切标签页，这几类都不能碰（`Ctrl+数字` 这类浏览器保留键网页拦不住，其余则是不该跟用户抢的通用键），而 `Alt+字母` 在 Chrome 里没有任何绑定。macOS 上 Option+字母打出的是特殊字符（å/ß/Ω/≈），故 mac 走 ⌘+⌥。键位定义收进 `core/mdFormat.ts` 的 `FORMAT_KEYS` 一处，工具栏提示、右键菜单、内置使用说明、快捷键绑定同源，不再出现「改了绑定、提示还写着旧键」。

- **选项批注**：刷题时答案出现后，每个选项右侧多一支铅笔，可写下「这个选项为什么对 / 为什么错」。批注按选项下标存进题库的 `optionNotes`，随备份导出、随题库保存；重练同一题直接显示，重新导入同名题库会按「题干 + 选项」把旧批注接回新题（否则修订版题库一到手，用户自己写的东西就静默没了）。选项按钮作答后即 `disabled`，铅笔必须是它的兄弟节点——按钮不能套按钮，因此选项行改成两列网格（选项 + 铅笔），批注显示在选项正下方、与选项文字左对齐。Esc 在批注框里只退出编辑，不关整个面板。
- **离线便携包不再有「换端口就看不到笔记」的坑**：浏览器按「地址」存 IndexedDB，端口也算地址的一部分，而启动脚本原本从 8790 起试第一个空闲端口——双击两次就会在 8791 起第二个服务，看到的是空库。现在启动前先查本机监听端口（`Get-NetTCPConnection`，一次查询；逐个 connect 探测在 Windows 上每个端口要等约 2 秒，不可用），若范围内已有 KnowLattice 在跑就直接打开它，不再另起一个；万一被迫换端口，黑窗口用黄字写明「换端口 = 另一个网站、这个地址下是空库」。收件人说明同步补齐地址与数据的关系。

## 打包与分发

### 网页版（推荐，发链接就能用）

```bash
npm install
npm run build
```

- dist/ 是纯静态产物，上传到任意静态托管即可（GitHub Pages / Vercel / 对象存储）。
- 已内置 PWA 清单：手机浏览器可「添加到主屏幕」当 App 用。
- 数据只存在本机浏览器（IndexedDB）：换设备或清缓存会丢，请定期「导出备份」。

### 离线便携包（发给别人，接收方零安装）

```bash
npm run pack                 # 构建 + 打成一个 zip
npm run pack -- --no-build   # 跳过构建，用现有 dist
npm run pack -- --data 某份备份.json   # 指定随包资料
```

产出仓库根目录 `KnowLattice-离线版-YYYY-MM-DD.zip`（同一天重复打包会覆盖同名产物），结构：

```
Start-KnowLattice.bat   双击启动（Windows；内部起一个只监听 127.0.0.1 的小服务，无依赖、无需安装）
server.ps1           该服务本体（Windows 自带 PowerShell 5.1 即可）
start-knowlattice.command   双击启动（macOS / Linux；同一个服务，行为与 .ps1 对齐）
server.py            该服务本体（macOS / Linux；Python 3 标准库，零依赖）
app/                 构建产物（全部功能，离线可用）
data/notes-and-qbanks.json   随包笔记 + 题库 + SRS/错题/待办/打卡/卡片自定义（由备份 .json 合并而来）
source/              对应源代码（GPL-3.0 第 6 节要求随程序提供）
README.txt           给接收方的一页说明
LICENSE              GPL-3.0 全文
THIRD-PARTY-NOTICES.md
```

- 包里 `app/` 是完整的构建产物（含 OCR 与全部字体）——**不再有「精简版」**：`--lite` 会直接报错退出，理由见上（省下的 7.3 MB 里 6.73 MB 是 OCR，去掉即砍掉「扫描版 PDF」）。`source/`、`data/`、启动器照常齐全。

- 为什么需要一个小服务：产物是 ES module + WASM，浏览器用 `file://` 打开会被 CORS 拦，必须经 HTTP 提供；服务只绑定本机回环地址，不联网、不上传数据。
- **构建前会先清 `dist`**（`package.json` 的 `prebuild` → `scripts/clean-dist.mjs`）：本机 `fs.rmSync` 会静默失效，vite 的 `emptyOutDir` 因此清不掉旧分块，会连带打进包（见「最近更新」里的记录）。清不掉直接中止，不产出脏包。
- 随包资料来自仓库根目录的 `knowlattice-*.json`（应用导出的备份），按 `files` 路径**去重合并**、`qbanks` 合并；因此多份备份会被合成一份。
- 自动收录有 **8 MB 体积闸门**：题库类备份动辄几十 MB（111548 道题那份 54 MB），自动收进来会把分享包从 41 MB 撑到 100 MB，而同学拿到一堆题库备份也不是「起步数据」。超限的会被跳过并打印一行说明，真要收就用 `--data` 显式指定——显式指定意味着你知道自己在装什么。
- `npm run pack` 会打印**随包数据摘要**（多少篇笔记 / 几份题库 / 多大 / 笔记顶层目录分布 / 每份来源文件）。分享前看这一行就知道包里有没有不该带的东西。
- 想带上「应用里刚改过的最新笔记」：先在应用里「⋯ → 备份到 .json」，再 `npm run pack -- --data <刚导出的文件>`。

#### 离线版与网页版的功能一致性（改代码时必须走一遍）

离线包的 `app/` 就是 `dist/` 的逐字节拷贝（源码另在 `source/`，与这条规矩无关），靠 `base: './'` 这一份产物同时喂网页版与便携包。所以功能一致不是靠两边各写一遍，而是靠这条规矩：

> 改完 `src/`、`public/`、`index.html` 或依赖 → 交付前必须重新 `npm run pack`，否则离线包会静默停在旧版本。

各文件是否进包，决定了要不要重打：

| 改动 | 是否进离线包 | 需要 |
| --- | --- | --- |
| `src/` `public/` `index.html` `package.json` | 进（经 `dist/`） | `npm run pack`（内含构建） |
| `scripts/*.mjs`（构建/打包脚本本身） | 进 `source/` | `npm run pack` |
| `scripts/pack/*`（启动器、收件人说明） | 进 | `npm run pack -- --no-build` |
| `THIRD-PARTY-NOTICES.md` | 进 | `npm run pack -- --no-build` |
| `README.md`、`.github/` | 不进 | 无需重打 |

另外两条：

- **分发的是 zip，不是解压出来的目录。** 目录里容易混进随手拷的备份、旧的构建产物；`npm run pack` 的产物才是可复现的那一份（解压目录已被 `.gitignore` 忽略）。
- **离线版的数据按「地址」隔离。** 浏览器把 `http://127.0.0.1:8790` 与 `:8791` 当作两个网站，各有各的 IndexedDB。启动脚本因此先探测范围内是否已有 KnowLattice 在跑，有就直接打开那一个，不另起第二个服务；被迫换端口时会黄字提示「这个地址下是空库」。`server.ps1` 里这段逻辑与收件人说明 `scripts/pack/README.txt` 是一体的，改一个要改另一个。

## 已知缺口

- **（已修复 2026-09-20）3D 解剖图谱的「神经系统」缺模型文件**：`public/anatomy/manifest.json` 的 `systems` 列了 12 个系统（`nervous` 含 525 个结构，每个结构的 `mesh_file` 都写 `nervous_male.glb`），但 `public/anatomy/nervous_male.glb` 长期不存在，点开神经系统必然 `fetch` 404。
  - **查证记录**（因为一度被怀疑是「改代码时误删」，所以逐条留证）：git 基线提交 `78f8310`（2026-09-14 19:36，视觉精修开工前的回滚点）里 `public/anatomy/` 就只有现在这 12 个 glb，没有 `nervous_male.glb`；`git log --diff-filter=D -- public/` 显示 `public/` 下**从未删除过任何 glb**（历史里只删过 3 个 `public/draco/*`）；本机另有一份 **2026-09-20 00:18 解压出来的离线包**（比本次改动早 23 小时），其 `app/anatomy/` 同样是 12 个 glb、同样没有 `nervous_male.glb`，且这 12 个文件与当前 `public/anatomy/` 的 SHA-256 **逐一相同**；全用户目录搜索 `*nervous*` 无任何文件，本机 8 个 zip 也都不含它。结论：该文件在本仓库从未存在过，**不是被删除的**——模型文件集（09-14 15:51 下载，含当时被误判为「未被 manifest 引用」的 `visceral_male.glb`——它其实被 13 条 organ 引用，见上面 09-21 那条）与 manifest（由上游元数据生成、含 `nervous`）来自两个不同口径的来源。
  - **修复方式**：从上游 [Anatria-3D](https://github.com/Nurkan1/Anatria-3D) 的 `public/anatomy/nervous_male.glb` 取回同源文件（8.14 MB，GLB 头声明长度与实际一致，Draco 压缩），放入 `public/anatomy/`。**不是随便找个模型塞进去**：写了对账脚本比对 manifest 中该系统的 `node` 字段与 GLB 节点名（应用点击命中就靠这个名字匹配），`nervous` **覆盖率 100%（525/525 结构命中，860 个节点）**——与对照组一致（其余 9 个单文件系统均为 100%）。当时 digestive 测出 89.4%、endocrine 60%、respiratory 89.5%，被记成「既有的小缺口」——**其实那 3 个的「缺口」就是同一个「一个系统一个文件」的错误假设造成的**（它们有相当一部分结构在 `visceral_male.glb` 里，而加载逻辑从没请求过那个文件），已于 2026-09-21 修掉，现在 12 个系统全部 100%，见上面 09-21 那条）。
  - **打包侧现在是两道闸门**（`scripts/pack.mjs`「2b. 解剖模型对账」）：① manifest 里**实际被引用**的每个 `mesh_file` 都必须在包里；② 每个结构只在**它自己那个文件**里找节点名，**覆盖率不得低于 50%**（拿错文件时覆盖率会趋近 0；重名不算命中，否则覆盖率虚高）。口径已于 2026-09-21 从「猜 `<system>_male.glb`」改成按 manifest 的 `mesh_file` 逐个查（见上面 09-21 那条）。任一不满足即中止打包并打印原因——这类「manifest 说有、包里没有/对不上」的事故不会再悄悄进包。
  - 应用侧也保留了对应话术：模型取不到时提示「`<file>` 没有随包提供……其它系统不受影响」，而不是把 three.js 的 `HttpError` 英文原文丢给用户。
  - 代价：离线包从 36.3 MB 增至 **41.3 MB**（神经系统 glb 8.14 MB，压缩后 +5.04 MB）。若日后要瘦身，这是可权衡的一项，但需要同时改 manifest，否则用户又会点到一个空系统。
