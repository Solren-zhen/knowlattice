# 晶格 · KnowLattice

KnowLattice 是一款本地优先的个人知识库与学习工具，面向医学生和需要长期整理知识的学习者。
它把笔记、复习、题库、任务和医学图谱放在同一个工作空间中。数据默认保存在本机浏览器里，也可以导出备份或制作离线包。

## 功能

### 笔记与知识库

- Markdown 笔记、章节树、frontmatter 和附件管理
- [[双链]]、链接补全、反向链接和全库知识图谱
- 全文搜索、标题搜索、中文近似检索和模糊匹配
- 编辑器与实时预览并排工作，支持常用格式工具和行内快捷操作
- 笔记中的待办任务可以直接在任务面板中查看和勾选

### 医学学习

- 3D 解剖图谱：12 个系统、3478 个结构，中英文检索和结构定位
- 点击解剖结构查看或创建对应笔记，结构与笔记双向关联
- 间隔复习：按笔记小节生成知识卡片，使用 FSRS 安排每日复习
- 真题标记、错题归档和薄弱章节定位
- 题库导入与练习，支持选择题、简答题、章节筛选和自动组题
- 选项批注、逐题复习记录和错题回到对应章节笔记

### 任务与专注

- 三栏待办工作区：智能列表、分组、搜索、排序、批量操作和详情编辑
- 一句话创建任务，可设置日期、优先级、关联笔记和重复规则
- 重复任务自动顺延，删除支持撤销，逾期任务可一键调整
- 专注计时、阶段切换、待办关联和专注统计
- 今日与累计数据、近 7 天趋势、任务完成率和学习打卡热力图

### 讲义与资料整理

- PDF 讲义对照阅读、搜索、缩放、翻页和文字选择
- Word 文档预览
- 从讲义摘录原文，追加到新笔记或已有笔记
- 从 PDF 或讲义内容生成结构化笔记草稿，审核后再保存
- Anki 卡片导出

### AI 与扩展

- 侧栏内嵌常用网页 AI 服务，便于学习时查询和整理
- 支持导入 JSON 题库，以及将章节题库批量转换为笔记和练习数据
- 支持 Web 版和本地离线便携包

### 数据与备份

- 笔记和附件保存在浏览器 IndexedDB，不依赖远程数据库
- 一键导出和恢复学习数据，包括笔记、附件索引、复习记录、题库、错题、待办和卡片自定义
- 可导出 Markdown 文件夹和图片附件，方便迁移到其他工具
- 可生成包含应用、启动器和源代码的离线包

## 运行

需要 Node.js 20 或更高版本。

~~~bash
npm install
npm run dev
~~~

打开终端显示的本地地址即可使用。

常用命令：

~~~bash
npm run build        # 构建静态网页
npm run preview      # 预览构建结果
npm run pack         # 生成离线便携包
~~~

## 数据位置

Web 版数据保存在当前浏览器的本地存储中。清理浏览器数据或更换设备前，请先从应用菜单导出备份。

离线便携包通过本机地址提供页面，数据仍保存在使用它的那台设备上，不会自动上传。
