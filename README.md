# 晶格 · KnowLattice

KnowLattice 是一款本地优先的个人知识库与学习工具，面向医学生和需要长期整理知识的学习者。
它把笔记、复习、题库、任务和医学图谱放在同一个工作空间中。数据默认保存在本机浏览器里，也可以导出备份或制作离线包。

## 功能

### 笔记与知识库

- Markdown 笔记、章节树、frontmatter 和附件管理
- [[双链]]、链接补全、反向链接和全库知识图谱
- 全文搜索、标题搜索、中文近似检索和模糊匹配
- 编辑器与实时预览并排工作，支持常用格式工具和行内快捷操作
- 笔记中的待办任务可以直接在任务面板中查看和勾选

### 医学学习

- 3D 解剖图谱：12 个系统、3478 个结构，中英文检索和结构定位
- 点击解剖结构查看或创建对应笔记，结构与笔记双向关联
- 间隔复习：按笔记小节生成知识卡片，使用 FSRS 安排每日复习
- 真题标记、错题归档和薄弱章节定位
- 题库导入与练习，支持选择题、简答题、章节 / 考点标签（高频·易错·在学·已掌握）/ 难度 筛选和自动组题
- 搜题：跨题库按关键词找题（题干 / 考点 / 选项 / 解析都参与匹配，缩写自动匹配学名，如「心梗」能找到「心肌梗死」），结果里可直接单题精练或收藏
- 选项批注、逐题复习记录和错题回到对应章节笔记
- 模拟考试：限时整卷、交卷自动评分、分章节成绩报告与历史对比（考试中心）
- 每日一练：按日期确定性抽出的今日题单，独立连续打卡与打卡热力
- 背题模式：不判分、直接摊开答案快速过一遍
- 收藏 / 重点题：练习与背题时一键把题标为重点，之后组题或模拟考试都能选「收藏题」范围单独刷；收藏随备份保存
- 错题重练：做错过的题再练一遍，答对移出错题池、答错加重
- 高频考点与难度分级：按章节题量、作答正确率与 FSRS 难度给题打标
- 薄弱点雷达图：跨题库合并的章节掌握度可视化

### 任务与专注

- 三栏待办工作区：智能列表、分组、搜索、排序、批量操作和详情编辑
- 一句话创建任务，可设置日期、优先级、关联笔记和重复规则
- 重复任务自动顺延，删除支持撤销，逾期任务可一键调整
- 专注计时、阶段切换、待办关联和专注统计
- 今日与累计数据、近 7 天趋势、任务完成率和学习打卡热力图

### 讲义与资料整理

- PDF 讲义对照阅读、搜索、缩放、翻页和文字选择
- Word 文档预览
- 从讲义摘录原文，追加到新笔记或已有笔记
- 从 PDF 或讲义内容生成结构化笔记草稿，审核后再保存
- Anki 卡片导出

### AI 学习助手

- 内置导师式 AI 助手：讲解自动用 [[双链]] 挂回知识网络、结尾收敛成考点，医学内容拿不准会明说不确定并建议核对教材
- 学习陪练契约：先测后讲（先出题再解释）、一次只问一个问题、答错先给提示再揭示、讲完必验证——防止「一次讲完所有内容，感觉高效实则没学到」
- 内置学习命令：`/陪练`（一次一题的教练模式）、`/费曼`（你讲它挑错）、`/出题`（先答后评）、`/串联`（跨笔记补双链）、`/错题归因`（定位共性薄弱点）
- 学习日志自动落盘：一轮问答/自测告一段落，助手把主题、薄弱点、练习结果写进当天的 `学习日志/` 笔记（同样走对比预览确认），下次会话可从日志续上薄弱点；日志不进复习队列
- 助手可感知学习状态：今日到期复习卡、连续打卡、近 7 天学习概况、错题本薄弱章节、题库练习进度，据此安排复习顺序与补救；「今日计划」按钮把代码算好的到期卡与错题本状态直接注入对话
- 为笔记小节补充复习卡提示键（如「定义: 」），直接提高复习卡质量
- 写入默认走「对比预览 → 应用」；「自主」模式下助手可直接修改笔记，笔记被手动改动过时仍强制人工确认，全部改动可回溯
- 接任意 OpenAI 兼容模型或 API 中转站，支持流式输出、工具调用与 @ 笔记引用；agent 引擎基于开源 pi-agent-core，按需加载不影响首屏
- 可在「设置 → 医学教材库」导入教材 PDF 建立本机索引，助手能检索教材原文、按页阅读、引用后自动核验；支持页码偏移换算（物理页 → 印刷页）、扫描版 OCR 导入和自定义等价词表
- 侧栏内嵌常用网页 AI 服务，便于学习时查询和整理

### 扩展与分发
- 支持导入 JSON 题库，以及将章节题库批量转换为笔记和练习数据
- 支持 Web 版和本地离线便携包

### 数据与备份

- 笔记和附件保存在浏览器 IndexedDB，不依赖远程数据库
- 一键导出和恢复学习数据，包括笔记、附件索引、复习记录、题库、错题、待办和卡片自定义
- 可导出 Markdown 文件夹和图片附件，方便迁移到其他工具
- 可生成包含应用、启动器和源代码的离线包

## 运行

需要 Node.js 20 或更高版本。

~~~bash
npm install
npm run dev
~~~

打开终端显示的本地地址即可使用。

常用命令：

~~~bash
npm run build        # 构建静态网页
npm run preview      # 预览构建结果
npm run pack         # 生成离线便携包
npm run bench        # 性能基线（5000 篇量级核心路径耗时，只测量不断言）
~~~

## 数据位置

Web 版数据保存在当前浏览器的本地存储中。清理浏览器数据或更换设备前，请先从应用菜单导出备份。

离线便携包通过本机地址提供页面，数据仍保存在使用它的那台设备上，不会自动上传。
