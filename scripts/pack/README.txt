MedVault（晶格）离线版 · 使用说明
==================================

一、启动
  1. 双击本文件夹里的  Start-MedVault.bat
  2. 会弹出一个黑色命令窗口（这是跑在你自己电脑上的小网页服务，正常现象），
     并自动用默认浏览器打开应用。
  3. 用完直接关闭那个黑窗口即可。

  本程序只在 127.0.0.1（本机回环地址）上提供页面，不联网、不上传任何数据。
  首次运行时 Windows 可能弹出安全提示，选择「允许访问 / 仍要运行」即可。

二、导入随包资料（笔记 + 题库）
  1. 在应用左侧目录栏，点右上角的「⋯」（更多操作）
  2. 选择「从备份 .json 恢复」
  3. 选择本文件夹里的  data/notes-and-qbanks.json
  4. 提示「已恢复 N 篇笔记」后，目录树里就会出现全部笔记；
     「题库练习」里能看到对应题库。

  说明：应用是「合并导入」——同名笔记覆盖，其余保留，所以可以先建自己的
  笔记再导入，不会互相清空。

三、数据存在哪里
  只存在你自己的浏览器里（IndexedDB）。换浏览器、换电脑、清理浏览器数据
  都会丢，请养成定期「⋯ → 备份到 .json」导出一份的习惯。

四、常见问题
  · 黑窗口一闪就没了：右键 Start-MedVault.bat →「以管理员身份运行」。
  · 浏览器没自动打开：查看黑窗口里显示的地址（形如 http://127.0.0.1:8790/），
    手动复制到浏览器地址栏打开。
  · 端口被占用：程序会自动换一个端口，以黑窗口里显示的地址为准。
  · 关掉黑窗口后网页打不开是正常的：它是本机的临时服务，再双击启动即可。

五、目录结构
  app/                        应用本体（静态网页，含全部功能）
  data/notes-and-qbanks.json  随包笔记与题库备份
  server.ps1                  本机小服务器（用 Windows 自带 PowerShell，无需安装任何东西）
  Start-MedVault.bat          启动入口
  THIRD-PARTY-NOTICES.md      第三方组件与数据许可
