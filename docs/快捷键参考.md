# 快捷键参考

> 高效使用 KNOWLATTICE 的键盘快捷键速查表

## 全局快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + K` | 快速打开笔记 | 输入笔记名搜索并打开 |
| `Ctrl/Cmd + P` | 命令面板 | 输入命令名执行各种操作 |
| `Ctrl/Cmd + N` | 新建笔记 | 在当前文件夹新建笔记 |
| `Ctrl/Cmd + Shift + N` | 新建文件夹 | 在笔记列表中新建文件夹 |
| `Ctrl/Cmd + /` | 切换侧边栏 | 显示/隐藏右侧边栏 |
| `Ctrl/Cmd + B` | 切换笔记列表 | 显示/隐藏左侧笔记列表 |
| `Ctrl/Cmd + ,` | 打开设置 | 快速进入设置页面 |
| `Ctrl/Cmd + Shift + F` | 全库搜索 | 在所有笔记中搜索内容 |
| `F11` | 全屏模式 | 专注写作（Tauri 桌面版） |
| `Esc` | 关闭弹窗/对话框 | 取消当前操作 |

## 编辑器快捷键

### 基础编辑

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + S` | 保存笔记 | 自动保存通常已开启 |
| `Ctrl/Cmd + Z` | 撤销 | 可连续撤销多步 |
| `Ctrl/Cmd + Shift + Z` | 重做 | 恢复撤销的操作 |
| `Ctrl/Cmd + F` | 当前笔记内搜索 | 支持正则表达式 |
| `Ctrl/Cmd + H` | 查找替换 | 批量替换文本 |
| `Alt + ↑/↓` | 移动行 | 上下移动当前行 |
| `Ctrl/Cmd + D` | 删除行 | 删除光标所在行 |
| `Ctrl/Cmd + Shift + D` | 复制行 | 向下复制当前行 |

### Markdown 格式化

| 快捷键 | 功能 | 效果 |
|--------|------|------|
| `Ctrl/Cmd + B` | 加粗 | `**粗体**` |
| `Ctrl/Cmd + I` | 斜体 | `*斜体*` |
| `Ctrl/Cmd + U` | 下划线 | `<u>下划线</u>` |
| `Ctrl/Cmd + E` | 行内代码 | \`code\` |
| `Ctrl/Cmd + K` | 插入链接 | `[文字](URL)` |
| `Ctrl/Cmd + Shift + K` | 插入双链 | `[[笔记名]]` |
| `Ctrl/Cmd + ]` | 增加缩进 | 向右缩进 |
| `Ctrl/Cmd + [` | 减少缩进 | 向左缩进 |
| `Ctrl/Cmd + /` | 切换注释 | HTML 注释 `<!-- -->` |

### 标题与列表

| 快捷键 | 功能 | 效果 |
|--------|------|------|
| `Ctrl/Cmd + 1` | 一级标题 | `# 标题` |
| `Ctrl/Cmd + 2` | 二级标题 | `## 标题` |
| `Ctrl/Cmd + 3` | 三级标题 | `### 标题` |
| `Ctrl/Cmd + Shift + 8` | 无序列表 | `- 项目` |
| `Ctrl/Cmd + Shift + 9` | 有序列表 | `1. 项目` |
| `Ctrl/Cmd + Shift + 7` | 任务列表 | `- [ ] 待办` |
| `Ctrl/Cmd + ]` | 列表增加层级 | 嵌套列表 |
| `Ctrl/Cmd + [` | 列表减少层级 | 返回上一层 |

### 插入内容

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + V` | 粘贴图片 | 剪贴板中的图片直接插入 |
| `Ctrl/Cmd + Shift + V` | 纯文本粘贴 | 不保留格式 |
| `Ctrl/Cmd + Shift + I` | 插入代码块 | 三个反引号 + 语言 |
| `Ctrl/Cmd + Shift + Q` | 插入引用块 | `> 引用` |
| `Ctrl/Cmd + Shift + M` | 插入公式 | `$公式$` 或 `$$公式$$` |
| `Ctrl/Cmd + Shift + T` | 插入表格 | Markdown 表格模板 |

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + Click` | 打开链接 | 打开双链或外部链接 |
| `Ctrl/Cmd + Alt + ←` | 返回 | 返回上一个笔记 |
| `Ctrl/Cmd + Alt + →` | 前进 | 前往下一个笔记 |
| `Ctrl/Cmd + Tab` | 切换标签页 | 在多个打开的笔记间切换 |
| `Ctrl/Cmd + W` | 关闭标签页 | 关闭当前笔记 |
| `Ctrl/Cmd + Shift + T` | 重新打开标签页 | 恢复刚关闭的笔记 |

## 自定义快捷键

如需修改快捷键，进入：

**设置 → 快捷键 → 自定义**

示例配置（JSON 格式）：

```json
{
  "快速打开": "Ctrl+O",
  "新建笔记": "Ctrl+Shift+N",
  "全库搜索": "Ctrl+Shift+P"
}
```

保存后立即生效。

## 平台差异

### Windows / Linux

- `Ctrl` 键用于大部分快捷键
- `Alt` 键用于辅助功能

### macOS

- `Cmd` 键（⌘）用于大部分快捷键
- `Option` 键（⌥）等同于 `Alt`
- `Ctrl` 键用于特殊功能（如 Emacs 风格编辑）

### 移动端（计划中）

目前 KNOWLATTICE 主要面向桌面端，移动端快捷键将在后续版本支持。

## 提示与技巧

### 1. 命令面板（`Ctrl/Cmd + P`）

记不住快捷键？按 `Ctrl/Cmd + P` 打开命令面板，输入功能名称即可：

```
复习        → 开始复习
导出        → 导出笔记
深色模式     → 切换主题
```

### 2. 快速链接（`[[`）

输入 `[[` 会自动弹出笔记列表，支持模糊搜索：

```
[[心衰   → 自动补全为 [[心力衰竭]]
```

### 3. 标签补全（`#`）

输入 `#` 会提示已有标签：

```
#内科   → 自动补全为 #内科学
```

### 4. Vim 模式（高级）

如果你熟悉 Vim，可以在设置中启用 Vim 键位：

**设置 → 编辑器 → 启用 Vim 模式**

常用 Vim 命令：
- `j` / `k`：上下移动
- `d` `d`：删除行
- `y` `y`：复制行
- `/`：搜索
- `:w`：保存
- `:q`：关闭
