# KNOWLATTICE 快速上手指南

> 本地优先的医学知识管理与学习工具

## 第一次使用

### 1. 安装与启动

```bash
# 开发模式（需要 Node.js 18+）
npm install
npm run dev
```

应用会在浏览器中打开（默认 http://localhost:5173）。

### 2. 创建知识库

首次启动会提示创建知识库：
- **浏览器模式**：数据存储在 IndexedDB（便携，无需文件系统权限）
- **本地文件夹**：选择一个空文件夹作为笔记库根目录（推荐，便于备份与同步）

推荐选择**本地文件夹**模式，方便后续用 Git/坚果云等工具同步。

### 3. 界面布局

```
┌──────────────────────────────────────────┐
│  [笔记列表]  │   [编辑器]   │  [侧边栏]  │
│              │              │            │
│  • 搜索框    │  Markdown    │  • 大纲    │
│  • 文件夹树  │  双链支持    │  • 知识图谱│
│  • 标签过滤  │  实时预览    │  • AI 助手 │
│              │              │  • 任务    │
└──────────────────────────────────────────┘
```

快捷键：
- `Ctrl/Cmd + K`：快速打开笔记
- `Ctrl/Cmd + P`：命令面板
- `Ctrl/Cmd + /`：切换侧边栏
- `Ctrl/Cmd + N`：新建笔记

### 4. 创建第一篇笔记

1. 点击左上角"新建笔记"或按 `Ctrl/Cmd + N`
2. 输入笔记标题（会自动创建 `.md` 文件）
3. 开始编写内容

**Markdown 语法**：
```markdown
# 一级标题

## 二级标题

- 无序列表
- [[双向链接]]  ← 输入 [[ 会自动提示现有笔记
- #标签 ← 可用于分类和过滤

**粗体** *斜体* `代码`

> 引用块

\```javascript
// 代码块
console.log('Hello');
\```
```

### 5. 导入资料

**导入 PDF 讲义**：
1. 侧边栏 → "资料" → "导入 PDF"
2. 选择 PDF 文件（支持批量）
3. 系统会提取文本，创建对应笔记

详细导入说明请参考 [资料导入.md](./资料导入.md)

**导入 Word 文档**：
- 直接拖拽 `.docx` 文件到笔记列表
- 会自动转换为 Markdown

**导入图片**：
- 在编辑器中直接粘贴图片（Ctrl/Cmd + V）
- 或拖拽图片文件到编辑器
- 图片自动保存到 `_attachments/` 文件夹

## 核心功能速览

### 📝 双向链接与知识图谱

- 输入 `[[` 可链接到其他笔记
- 侧边栏"知识图谱"可视化笔记关联
- 点击图谱节点快速跳转

### 🧠 间隔复习（FSRS 算法）

1. 创建复习卡片：在笔记中用 `---` 分隔问题与答案
   ```markdown
   ## 心肌梗死的典型心电图表现？
   ---
   ST 段弓背抬高 + 异常 Q 波 + T 波倒置
   ```
2. 侧边栏 → "复习" → 开始复习
3. 根据记忆程度点击"忘记/困难/良好/轻松"
4. 系统自动计算下次复习时间（基于 FSRS 算法）

### 🎯 题库练习

1. 侧边栏 → "练习" → "导入题库"
2. 支持 JSON 格式题库（格式参考：[题库格式规范.md](./题库格式规范.md)）
3. 练习模式：
   - **随机练习**：全库随机出题
   - **章节练习**：按章节分类练习
   - **模拟考试**：限时答题，自动评分
   - **错题本**：自动收录错题，标注错因

### 🤖 AI 学习助手

**配置 API**（首次使用）：
1. 侧边栏 → "设置" → "AI 助手"
2. 填入 OpenAI 兼容的 API 地址与密钥
   - 支持 OpenAI、Anthropic、Azure OpenAI、本地 Ollama 等
3. 可选：在「设置 → AI 笔记 → 医学教材库」导入教材 PDF（AI 可检索教材原文并核验引用）

**内置学习命令**（只有这六个；想加自己的命令，在库里建 `AI命令/<名字>.md`）：
- `/陪练`：苏格拉底式对话，先测后讲、一次一题
- `/费曼`：你先讲，AI 扮演较真的同学挑错、逐条追问
- `/出题`：先给题、作答后逐题点评
- `/串联`：在库里找相关笔记，补 `[[双链]]`
- `/追问`：一次给 3-5 个精加工追问，先不给答案
- `/错题归因`：按四类错因归因，分派补救动作

详细用法：[AI 助手使用指南.md](./AI助手使用指南.md)

### 🔬 3D 解剖图谱

1. 侧边栏 → "解剖" → 选择系统（如"心血管系统"）
2. 3D 模型可旋转、缩放、透视
3. 点击结构查看名称与相关笔记
4. 右键保存视角，插入笔记

### ⏱️ 专注模式与学习统计

- **专注计时**：侧边栏 → "专注"，番茄钟 25 分钟
- **学习统计**：查看每日学习时长、复习次数、正确率
- **学习日历**：可视化学习连续天数

## 常见问题

**Q: 如何备份数据？**  
A: 
- 浏览器模式：侧边栏 → "设置" → "导出数据"（导出为 `.zip`）
- 文件夹模式：直接复制整个笔记文件夹，或用 Git 管理

**Q: 能否在多设备间同步？**  
A: 
- 文件夹模式可用坚果云/OneDrive/iCloud 自动同步
- 浏览器模式需手动导出/导入

**Q: Markdown 不会怎么办？**  
A: 
- 参考：[Markdown 基础语法](https://markdown.com.cn/basic-syntax/)
- 或直接用工具栏按钮（编辑器顶部）

**Q: AI 助手回答不准确？**  
A: 
1. 确认使用的模型（推荐 GPT-4 或 Claude 3.5）
2. 在「设置 → AI 笔记 → 医学教材库」导入教材 PDF，提高准确性
3. 在对话中要求"引用教材原文"

**Q: PDF 导入后文字乱码？**  
A: 
- 确认 PDF 是文字版（非扫描版）
- 扫描版 PDF 需先 OCR 识别（推荐用 ABBYY FineReader）

**Q: 如何打包成桌面应用？**  
A: 
```bash
npm run pack
```
打包后的应用在 `src-tauri/target/release/bundle/` 目录。
