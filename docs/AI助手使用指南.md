# AI 助手使用指南

> KNOWLATTICE 内置基于 LLM 的学习导师，支持苏格拉底式对话、自动出题、引用教材原文等功能。

## 配置 AI 助手

### 1. 选择 API 服务商

KNOWLATTICE 支持任何 OpenAI 兼容的 `/chat/completions` 端点。面板里预置了下面几个常用入口
（点一下就会填好地址与模型名，也可以自己改）：

| 服务商 | API 地址 | 说明 |
|--------|---------|------|
| **小米 MiMo** | `https://api.xiaomimimo.com/v1` | 每日有免费额度，模型名以控制台为准 |
| **智谱 GLM** | `https://open.bigmodel.cn/api/paas/v4` | 默认 `glm-4.6` |
| **DeepSeek** | `https://api.deepseek.com/v1` | 默认 `deepseek-chat` |
| **Kimi** | `https://api.moonshot.cn/v1` | 默认 `kimi-k2` |
| **OpenRouter** | `https://openrouter.ai/api/v1` | 可访问海外模型，模型名填 `provider/model` |
| **Ollama 本地** | `http://localhost:11434/v1` | 无需密钥；需以 `OLLAMA_ORIGINS=*` 启动以放行跨域 |
| **自定义中转** | 中转站给的地址（通常以 `/v1` 结尾） | 粘贴后先点「测试连接」 |

> 远程接口必须使用 `https://`。`http://` 只允许 `localhost`、`127.0.0.1` 和 `[::1]`，避免 API Key 明文经过网络。

OpenAI / Anthropic / Azure OpenAI 等也可以，填它们提供的 OpenAI 兼容地址即可——
模型名请以服务商控制台为准，别照抄示例。

### 2. 填写配置

打开侧栏的「AI 笔记」面板 → 右上角「设置」：

```yaml
接口地址: https://api.deepseek.com/v1
API Key:  sk-xxxxxxxxxxxxxxxxxxxxxxxx
模型名:    deepseek-chat
```

填好点「测试连接」——它会真发一条短请求；成功后会顺便拉取模型列表做输入候选。
中转站地址若漏了版本段（返回 404），会自动补 `/v1` 重试一次并回填地址。

**本地 Ollama 示例**：
```yaml
接口地址: http://localhost:11434/v1
API Key:  留空即可
模型名:   qwen2.5:14b
```

### 3. 导入教材 PDF（可选但推荐）

侧边栏 →「设置」→「AI 笔记」→「医学教材库」→ 点「导入教材 PDF」（支持批量选择）

- 系统在本机提取全文并建立索引（不联网、不上传）
- AI 回答时可检索教材原文、按页阅读，并核验引用
- 支持中英文教材；扫描版（没有文字层）普通导入会失败，可用「用 OCR 导入失败的书」走本地识别（每页约 2~5 秒）
- 教材正文存在本机 IndexedDB，可以在同一个面板里查看已导入清单、改页码偏移或删除

**推荐教材**：
- 人卫出版社第 9/10 版系列教材
- 各专业经典教材（如《协和内科学》）
- 真题解析与考点精粹

## 内置学习命令

在 AI 对话框中输入以下命令，快速启动特定学习模式。

### `/陪练` — 苏格拉底式对话

**用法**：`/陪练 心肌梗死的诊断`

AI 不会直接给答案，而是通过提问引导你主动思考：

**示例对话**：
```
你：/陪练 心肌梗死的诊断

AI：我们先从最基础的开始：你觉得诊断心肌梗死需要哪些信息？

你：临床症状、心电图、心肌酶？

AI：很好！那么，如果一个患者胸痛 3 小时，心电图正常，
    心肌酶也正常，能排除心梗吗？

你：不能，因为早期可能还没有改变。

AI：正确！那么在这种情况下，你会怎么做？
```

**适用场景**：
- 准备面试或病例分析
- 检验自己的临床思维
- 理清复杂疾病的诊疗逻辑

---

### `/费曼` — 用简单的话解释概念

**用法**：`/费曼 肾小球滤过率`

AI 会要求你用"给高中生讲课"的方式解释概念，暴露你理解上的漏洞。

**示例**：
```
你：/费曼 肾小球滤过率

AI：请用最简单的话解释"肾小球滤过率"，
    就像你在给一个高中生讲课。

你：就是肾脏每分钟能过滤多少血液。

AI：很好的开始！那么：
    1. 为什么不是"血液"，而是"血浆"？
    2. 正常人每分钟大约过滤多少毫升？
    3. 这个值下降到多少就算肾功能不全了？
```

**适用场景**：
- 复习基础概念
- 准备科普或带教
- 确认自己真正理解（而非死记硬背）

---

### `/出题` — 根据笔记自动生成测试题

**用法**：
1. 打开一篇笔记（如"心力衰竭"）
2. 在 AI 对话框输入：`/出题`
3. AI 会根据笔记内容生成 5-10 道题

**生成题型**：
- 单选题（A1 型）
- 多选题
- 病例分析题
- 机制解释题

**示例**：
```
/出题

AI 生成：
【题 1】男性，65 岁，活动后气促 2 月。查体：
     双肺底湿啰音，心尖部舒张期奔马律。
     最可能的诊断是？
     A. 慢性阻塞性肺疾病
     B. 左心衰竭
     C. 肺栓塞
     D. 支气管哮喘

【题 2】洋地黄类药物治疗心衰的主要机制是？
     ...
```

**高级用法**：
- `/出题 难度:困难` — 生成高阶题目
- `/出题 题型:病例` — 只生成病例分析题
- `/出题 数量:20` — 生成 20 道题

---

### `/串联` — 把知识连成网

**用法**：`/串联 心力衰竭`

AI 会先用 `search_notes` 在库里找相关笔记（不凭空猜库里有什么），列出「该主题应链接哪些笔记、哪些笔记该回链过来」并给出理由；你确认后，它用 `propose_note_patch` 逐篇补 `[[双链]]`，一次只改一处、逐一确认。

**适用场景**：
- 新写的笔记还没挂上双链
- 复习时发现某两个知识点该互相引用

---

### `/追问` — 用追问检验是不是真懂了

**用法**：`/追问 肾小球滤过率`

AI 先给 3-5 个「为什么 / 怎么解释 / 如果……会怎样 / 和某某怎么区分」的追问，**一次全给、不给答案也不给提示**；你逐条回答后，它只做两件事：指出答错或含糊的点，补上标准说法；最后列出这串追问能挂回知识网络的 `[[双链]]`。

**适用场景**：
- 感觉「看懂了」但说不清楚
- 考前检查精加工深度

---

### `/错题归因` — 定位共性薄弱点

**用法**：`/错题归因`（先粘贴错题，或直接让它看错题本）

AI 会先调 `get_weak_chapters` 看错题本里已有的错因分布与薄弱章节，再把错题逐题归到四类之一（知识没记住 / 概念混淆 / 审题偏差 / 临床推理跳步），归纳共性薄弱点并指出该回到哪篇笔记的哪一节，最后按错因分派补救动作。

**适用场景**：
- 一段时间做题错得多，想知道错在哪一类
- 决定下一步复习什么

---

### 想要更多命令：自己写一条

内置命令只有上面六个。想加自己的命令，在知识库里建一篇 `AI命令/<名字>.md`，
正文就是提示词（可用 `$ARGUMENTS` 占位符接收参数）——输入 `/名字` 时会展开成这篇笔记的内容，
库内同名命令优先于内置模板。

比如建 `AI命令/总结.md`：

```markdown
读当前打开的笔记，输出三部分：核心要点（3-5 条）、思维导图大纲、记忆口诀（适用时）。
要点必须来自笔记原文，不要补充笔记里没有的内容。
```

之后 `/总结` 就能用了。

## 高级功能

### 1. 引用教材原文

在对话中要求：`请引用教材原文`

AI 会从你上传的教材 PDF 中搜索相关段落并标注出处：

```
你：请引用教材原文解释"肾小球滤过率"

AI：根据《生理学（第9版）》第 7 章：

    〔p.142〕"肾小球滤过率（GFR）是指单位时间内
    两肾生成的超滤液量，正常成人约为 125 ml/min
    或 180 L/d。GFR 是衡量肾功能的重要指标。"

    当 GFR 下降到 60 ml/min 以下时，提示慢性肾脏病。
```

**引用标记说明**（`〔《书名》 P页码〕` 标注出处）：

回答下方会给每条引用一个核验徽标，分四档：

- `✓ 逐字命中`：引文与原文完全一致
- `~ 部分命中`：头尾都在原文里，中段有落差（多为拼接或省略）
- `✗ 未逐字命中`：只有开头或只有结尾能在原文里找到，疑似编造
- `? 未找到出处`：原文里查无此句

没给出原文的引用标记会照实列成「未给出原文」，表示无法逐字核验。
引用了教材的，徽标会直接比对本机教材原文（不依赖本轮是否检索过这本书）；
鼠标悬停可以看到命中的出处与「是否比对过本机教材」。

### 2. 对比笔记与教材

**用法**：打开笔记后，输入 `/对比教材`

AI 会：
1. 找出笔记中与教材**不一致**的地方
2. 指出笔记中**遗漏**的重要考点
3. 标注笔记中的**错误**

### 3. 生成 Anki 卡片

**用法**：`/制卡`

AI 会将笔记转换为问答格式，方便导入 Anki：

```
/制卡

AI 生成：
Q: 肾小球滤过率的正常值？
A: 125 ml/min 或 180 L/d

Q: GFR 下降到多少提示慢性肾脏病？
A: < 60 ml/min（持续 3 个月以上）

Q: 影响 GFR 的三大因素？
A: 1) 滤过膜通透性 2) 有效滤过压 3) 滤过面积
```

可直接复制，保存为 `.txt` 文件，导入 Anki。

## 最佳实践

### ✅ 推荐做法

1. **先导入教材**：准确性显著提升
2. **具体提问**：
   - ❌ "讲讲心衰"
   - ✅ "ACEI 和 ARB 在心衰中的区别是什么？"
3. **要求引用原文**：避免 AI 编造
4. **结合笔记使用**：打开笔记后再提问，AI 会参考笔记内容
5. **追问细节**：
   ```
   你：为什么 ACEI 能改善心衰预后？
   AI：[解释作用机制]
   你：那为什么不用 ARB？
   AI：[对比两者差异]
   ```

### ❌ 避免的做法

1. **过于依赖 AI**：AI 可能出错，重要内容需核对教材
2. **直接问答案**：用 `/陪练` 模式更能加深理解
3. **不验证引用**：看到引用标记后，最好翻开教材确认
4. **泄露个人信息**：不要在对话中提及真实姓名、学校等

## 故障排查

**Q: AI 回复"API 错误"**  
A: 
1. 检查网络连接
2. 确认 API 密钥正确
3. 检查账户余额（OpenAI 等需充值）
4. 查看控制台错误信息（F12 打开开发者工具）

**Q: AI 回答很慢**  
A: 
1. OpenAI 国内访问慢，考虑用 Azure 或代理
2. 本地 Ollama 速度取决于硬件（推荐 16GB+ 显存）

**Q: AI 乱编内容**  
A: 
1. 导入教材 PDF 并要求"引用原文"，回答下方会给出逐字核验徽标（✓ / ~ / ✗ / ?）
2. 使用更强的模型
3. 对于关键知识点，务必核对教材

**Q: 教材 PDF 导入失败**  
A: 
1. 确认是文字版 PDF（扫描版没有文字层，可用「用 OCR 导入失败的书」走本地识别）
2. 换一份未加密、未损坏的文件
3. 文件名不含特殊字符

**Q: 如何删除已导入的教材？**  
A: 侧边栏 →「设置」→「AI 笔记」→「医学教材库」→ 点教材右侧的 ✕

**Q: 密钥会被保存到哪里？**  
A: 默认保存在本机浏览器存储（localStorage），**不会随备份导出**；共用设备可在设置里取消
「把密钥保存在本机」，这样密钥只在本次会话内有效。桌面版更彻底的做法（交给系统凭据存储）尚未实现。

## 技术说明

KNOWLATTICE 的 AI 助手基于 `pi-agent-core` 引擎，支持：

- **流式输出**：逐字显示，体验流畅
- **上下文记忆**：会话历史按字符预算回传（约 2 万字，单条超长会截断），不是固定轮数
- **笔记检索**：中文按相邻两字滑窗做片段召回，叠等价词表（如「心梗」能召回「心肌梗死」）与标题加权
- **教材检索**：与笔记检索同一套片段规则与证据单元，按页分块、可换算印刷页码
- **分段读**：长笔记一次读不完，助手会用 `read_note` 的 `offset` 续读或 `heading` 按小节读
- **引用核验**：回答里的引用逐条与原文比对（四档），教材引用会直接比对本机教材原文
- **上下文预算**：单条工具结果与整轮累计都有上限，超出的旧结果会被省略（模型可重新调用取回）
- **Markdown 渲染**：支持公式、表格、代码高亮

**隐私保护**：
- 对话内容**以及助手检索到的笔记正文、教材原文**都会发给你配置的 API 服务商
- KNOWLATTICE 自身不存储、不上传任何对话记录；会话与配置只留在本机
- 教材 PDF 仅在本地解析与索引，不上传云端
- 密钥默认存在本机浏览器存储里，不随备份导出；可在设置里关掉保存
