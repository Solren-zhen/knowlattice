# AI 助手使用指南

> KNOWLATTICE 内置基于 LLM 的学习导师，支持苏格拉底式对话、自动出题、引用教材原文等功能。

## 配置 AI 助手

### 1. 选择 API 服务商

KNOWLATTICE 支持任何 OpenAI 兼容的 API：

| 服务商 | API 地址 | 推荐模型 | 说明 |
|--------|---------|---------|------|
| **OpenAI** | `https://api.openai.com/v1` | `gpt-4o`, `gpt-4-turbo` | 官方服务，需科学上网 |
| **Anthropic** | `https://api.anthropic.com/v1` | `claude-3-5-sonnet-20241022` | 推理能力强，擅长长文本 |
| **Azure OpenAI** | 见 Azure 控制台 | `gpt-4` | 国内可用，需企业账号 |
| **本地 Ollama** | `http://localhost:11434/v1` | `llama3.1`, `qwen2.5` | 免费，离线可用，需自行部署 |
| **第三方代理** | 各代理商提供 | 视代理而定 | 价格便宜，稳定性不保证 |

### 2. 填写配置

侧边栏 → "设置" → "AI 助手"

```yaml
API 地址: https://api.openai.com/v1
API 密钥: sk-xxxxxxxxxxxxxxxxxxxxxxxx
模型名称: gpt-4o
```

**Anthropic Claude 配置示例**：
```yaml
API 地址: https://api.anthropic.com/v1
API 密钥: sk-ant-xxxxxxxxxxxxxxxxxxxxxxxx
模型名称: claude-3-5-sonnet-20241022
```

**本地 Ollama 配置示例**：
```yaml
API 地址: http://localhost:11434/v1
API 密钥: ollama  # 任意非空字符串即可
模型名称: qwen2.5:14b
```

### 3. 上传教材 PDF（可选但推荐）

点击"上传教材" → 选择 PDF 文件（支持批量）

- 系统会提取全文并建立索引
- AI 回答时可自动引用教材原文
- 支持中英文教材
- 单个文件不超过 100MB

**推荐教材**：
- 人卫出版社第 9/10 版系列教材
- 各专业经典教材（如《协和内科学》）
- 真题解析与考点精粹

## 内置学习命令

在 AI 对话框中输入以下命令，快速启动特定学习模式。

### `/陪练` — 苏格拉底式对话

**用法**：`/陪练 心肌梗死的诊断`

AI 不会直接给答案，而是通过提问引导你主动思考：

**示例对话**：
```
你：/陪练 心肌梗死的诊断

AI：我们先从最基础的开始：你觉得诊断心肌梗死需要哪些信息？

你：临床症状、心电图、心肌酶？

AI：很好！那么，如果一个患者胸痛 3 小时，心电图正常，
    心肌酶也正常，能排除心梗吗？

你：不能，因为早期可能还没有改变。

AI：正确！那么在这种情况下，你会怎么做？
```

**适用场景**：
- 准备面试或病例分析
- 检验自己的临床思维
- 理清复杂疾病的诊疗逻辑

---

### `/费曼` — 用简单的话解释概念

**用法**：`/费曼 肾小球滤过率`

AI 会要求你用"给高中生讲课"的方式解释概念，暴露你理解上的漏洞。

**示例**：
```
你：/费曼 肾小球滤过率

AI：请用最简单的话解释"肾小球滤过率"，
    就像你在给一个高中生讲课。

你：就是肾脏每分钟能过滤多少血液。

AI：很好的开始！那么：
    1. 为什么不是"血液"，而是"血浆"？
    2. 正常人每分钟大约过滤多少毫升？
    3. 这个值下降到多少就算肾功能不全了？
```

**适用场景**：
- 复习基础概念
- 准备科普或带教
- 确认自己真正理解（而非死记硬背）

---

### `/出题` — 根据笔记自动生成测试题

**用法**：
1. 打开一篇笔记（如"心力衰竭"）
2. 在 AI 对话框输入：`/出题`
3. AI 会根据笔记内容生成 5-10 道题

**生成题型**：
- 单选题（A1 型）
- 多选题
- 病例分析题
- 机制解释题

**示例**：
```
/出题

AI 生成：
【题 1】男性，65 岁，活动后气促 2 月。查体：
     双肺底湿啰音，心尖部舒张期奔马律。
     最可能的诊断是？
     A. 慢性阻塞性肺疾病
     B. 左心衰竭
     C. 肺栓塞
     D. 支气管哮喘

【题 2】洋地黄类药物治疗心衰的主要机制是？
     ...
```

**高级用法**：
- `/出题 难度:困难` — 生成高阶题目
- `/出题 题型:病例` — 只生成病例分析题
- `/出题 数量:20` — 生成 20 道题

---

### `/解题` — 分析题目并给出解题思路

**用法**：
1. 复制题目
2. 输入：`/解题` + 粘贴题目

**示例**：
```
你：/解题
    男性，60 岁，突发胸痛 2 小时，
    心电图 V1-V4 ST 段抬高。
    首选治疗是？

AI：【思路】
    1. 识别病情：急性前壁 ST 段抬高型心梗（STEMI）
    2. 时间窗：发病 2 小时 < 12 小时，在再灌注治疗窗口内
    3. 首选：直接 PCI（急诊冠脉介入）
       - 如无 PCI 条件，溶栓治疗
    4. 同时给予：阿司匹林、氯吡格雷、低分子肝素

    【答案】直接 PCI（或溶栓治疗）

    【易错点】
    - 不要先做冠脉造影再决定，STEMI 直接上 PCI
    - 不要忘记抗血小板与抗凝
```

**适用场景**：
- 做题遇到不会的
- 错题复盘
- 学习标准解题思路

---

### `/总结` — 提取笔记要点

**用法**：
1. 打开一篇笔记
2. 输入：`/总结`

AI 会生成：
- **核心要点**（3-5 条）
- **思维导图大纲**
- **记忆口诀**（如果适用）

**示例**：
```
/总结

AI：【核心要点】
1. 急性心梗的"黄金 12 小时"再灌注窗口
2. STEMI → 直接 PCI；NSTEMI → 先稳定再决定
3. 早期（< 6h）溶栓效果接近 PCI
4. 禁忌症：活动性出血、近期脑卒中、主动脉夹层

【思维导图】
急性心梗
├── 诊断（症状 + ECG + 心肌酶）
├── 分型（STEMI vs NSTEMI）
├── 治疗
│   ├── 再灌注（PCI / 溶栓）
│   ├── 抗血小板（阿司匹林 + P2Y12 抑制剂）
│   ├── 抗凝（肝素 / 比伐芦定）
│   └── 其他（β 受体阻滞剂、ACEI、他汀）
└── 并发症（心律失常、心衰、心源性休克…）

【口诀】"梗死黄金十二时，双抗双疗稳病情"
```

## 高级功能

### 1. 引用教材原文

在对话中要求：`请引用教材原文`

AI 会从你上传的教材 PDF 中搜索相关段落并标注出处：

```
你：请引用教材原文解释"肾小球滤过率"

AI：根据《生理学（第9版）》第 7 章：

    〔p.142〕"肾小球滤过率（GFR）是指单位时间内
    两肾生成的超滤液量，正常成人约为 125 ml/min
    或 180 L/d。GFR 是衡量肾功能的重要指标。"

    当 GFR 下降到 60 ml/min 以下时，提示慢性肾脏病。
```

**引用标记说明**：
- `〔p.142〕`：来自第 142 页
- ✅ 绿色勾：引文与原文完全一致
- ⚠️ 黄色感叹号：引文有改写，但意思正确
- ❌ 红色叉：未找到原文支持

### 2. 对比笔记与教材

**用法**：打开笔记后，输入 `/对比教材`

AI 会：
1. 找出笔记中与教材**不一致**的地方
2. 指出笔记中**遗漏**的重要考点
3. 标注笔记中的**错误**

### 3. 生成 Anki 卡片

**用法**：`/制卡`

AI 会将笔记转换为问答格式，方便导入 Anki：

```
/制卡

AI 生成：
Q: 肾小球滤过率的正常值？
A: 125 ml/min 或 180 L/d

Q: GFR 下降到多少提示慢性肾脏病？
A: < 60 ml/min（持续 3 个月以上）

Q: 影响 GFR 的三大因素？
A: 1) 滤过膜通透性 2) 有效滤过压 3) 滤过面积
```

可直接复制，保存为 `.txt` 文件，导入 Anki。

## 最佳实践

### ✅ 推荐做法

1. **先上传教材**：准确性显著提升
2. **具体提问**：
   - ❌ "讲讲心衰"
   - ✅ "ACEI 和 ARB 在心衰中的区别是什么？"
3. **要求引用原文**：避免 AI 编造
4. **结合笔记使用**：打开笔记后再提问，AI 会参考笔记内容
5. **追问细节**：
   ```
   你：为什么 ACEI 能改善心衰预后？
   AI：[解释作用机制]
   你：那为什么不用 ARB？
   AI：[对比两者差异]
   ```

### ❌ 避免的做法

1. **过于依赖 AI**：AI 可能出错，重要内容需核对教材
2. **直接问答案**：用 `/陪练` 模式更能加深理解
3. **不验证引用**：看到引用标记后，最好翻开教材确认
4. **泄露个人信息**：不要在对话中提及真实姓名、学校等

## 故障排查

**Q: AI 回复"API 错误"**  
A: 
1. 检查网络连接
2. 确认 API 密钥正确
3. 检查账户余额（OpenAI 等需充值）
4. 查看控制台错误信息（F12 打开开发者工具）

**Q: AI 回答很慢**  
A: 
1. OpenAI 国内访问慢，考虑用 Azure 或代理
2. 本地 Ollama 速度取决于硬件（推荐 16GB+ 显存）

**Q: AI 乱编内容**  
A: 
1. 上传教材 PDF 并要求"引用原文"
2. 使用更强的模型（GPT-4 > GPT-3.5）
3. 对于关键知识点，务必核对教材

**Q: 教材 PDF 上传失败**  
A: 
1. 确认文件是文字版 PDF（非扫描版）
2. 单个文件 < 100MB
3. 文件名不含特殊字符

**Q: 如何删除已上传的教材？**  
A: 侧边栏 → "设置" → "AI 助手" → "教材管理" → 点击教材旁的"删除"按钮

## 技术说明

KNOWLATTICE 的 AI 助手基于 `pi-agent-core` 引擎，支持：

- **流式输出**：逐字显示，体验流畅
- **上下文记忆**：记住对话历史（单次会话最多 20 轮）
- **教材检索**：基于 BM25 算法快速定位相关段落
- **引用核验**：自动比对 AI 回答与原文的一致性
- **Markdown 渲染**：支持公式、表格、代码高亮

**隐私保护**：
- 对话内容仅发送到你配置的 API 服务商
- KNOWLATTICE 不存储或上传任何对话记录
- 教材 PDF 仅在本地处理，不上传云端
