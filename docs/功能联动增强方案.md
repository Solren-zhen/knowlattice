# 功能联动增强方案

## 现状分析

KNOWLATTICE 已有丰富的功能模块，但它们之间的联动还比较薄弱：

| 功能模块 | 当前状态 | 联动缺失 |
|---------|---------|---------|
| **笔记** | Markdown + 双链 + 知识图谱 | 与题库/复习/任务的关联是单向的 |
| **复习卡片** | FSRS 间隔复习 | 不知道这张卡对应哪些题、错了几次 |
| **题库练习** | 错题本 + 统计 | 错题不会自动生成复习卡片 |
| **任务管理** | 待办 + 专注计时 | 完成任务不影响学习统计 |
| **AI 助手** | 对话 + 出题 | 生成的题没有自动入库 |
| **3D 解剖** | 可视化 + 笔记关联 | 看完解剖不会提示复习相关笔记 |
| **学习统计** | 时长 + 正确率 | 数据孤立，没有融合各模块 |

## 联动增强方案（10 项）

### 1. 错题 → 自动生成复习卡片 ⭐⭐⭐

**场景**：做题时答错 3 次以上的题，说明这个知识点没掌握。

**联动机制**：
```typescript
// src/core/qbankCards.ts (新建)
export interface MistakeCard extends ReviewCard {
  /** 来源题目 ID */
  questionId: string;
  /** 错误次数 */
  mistakeCount: number;
  /** 最近错误的时间 */
  lastMistakeAt: number;
}

/**
 * 从错题自动生成复习卡片
 * - 错 3 次以上 → 生成卡片
 * - 卡片正面：题干
 * - 卡片背面：正确答案 + 解析 + 关联笔记链接
 */
export function generateCardsFromMistakes(
  mistakes: MistakeRecord[]
): MistakeCard[]
```

**UI 体验**：
- 错题本页面显示"生成复习卡片"按钮（显示"3 道题可生成卡片"）
- 点击后批量加入复习队列，标记为"错题卡"
- 复习时卡片底部显示"来自错题：[题目链接]"

**收益**：错题不会被遗忘，定期复习直到掌握。

**收益**：复习与做题相互印证，加深记忆。

### 4. AI 出题 → 直接入库 ⭐⭐⭐

**场景**：AI 生成了 5 道题，但还要手动复制粘贴成 JSON 才能导入。

**联动机制**：
- AI 对话框增加"加入题库"按钮
- 点击后：
  1. 解析 AI 回复中的题目（Markdown → JSON）
  2. 自动填充 `chapter`（从当前打开的笔记获取）
  3. 自动填充 `note`（关联到当前笔记）
  4. 批量导入题库

**实现**：
```typescript
// src/core/aiQuestionImport.ts (新建)
/**
 * 从 AI 回复中提取题目并转换为 QuizQuestion[]
 * 支持格式：
 * - 【题1】题干\nA. 选项...\n答案：B
 * - 1. 题干...\n- A. 选项...\n- 答案：B
 */
export function parseAiQuestions(
  aiResponse: string,
  chapter: string,
  notePath: string
): QuizQuestion[]
```

**收益**：AI 出题无缝融入学习闭环。

### 5. 任务完成 → 学习统计联动 ⭐⭐

**场景**：完成了"复习呼吸系统"任务，但学习统计里没体现。

**联动机制**：
- 任务标记为完成时，检查是否包含学习关键词：
  - "复习" → 学习时长 +30 分钟（预估）
  - "做题" → 题目数 +1
  - "看讲义" → 阅读时长 +1 小时
- 写入学习日志（`src/core/stats.ts`）

**实现**：
```typescript
// src/core/taskStats.ts (新建)

  if (learningAction) {
    addStatsEntry({
      type: learningAction.type,
      duration: learningAction.estimatedMinutes,
      at: Date.now(),
    });
  }
}
```

**收益**：任务管理与学习统计融合，数据更完整。

## 用户体验优化

### 自动化 vs 手动控制

**自动化**（无感知）：
- 错题自动生成卡片（后台）
- AI 出题自动关联当前笔记
- 专注计时自动记录学习内容

**手动控制**（需确认）：
- 批量生成卡片前显示预览
- 学习路径推荐可以调整顺序
- 关联题目可以取消关联

### 渐进式披露

避免信息过载：
- 默认只显示最相关的 3-5 条
- 点击"查看全部"展开完整列表
- 可设置"关闭某类推荐"
