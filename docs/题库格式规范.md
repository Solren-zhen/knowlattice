# 题库格式规范

> KNOWLATTICE 支持导入 JSON 格式的题库，用于日常练习、模拟考试和错题管理。

## 基本格式

题库文件为 `.json` 格式，结构如下：

```json
{
  "name": "内科学题库",
  "version": "1.0",
  "description": "第10版人卫教材配套",
  "tags": ["内科", "真题"],
  "questions": [
    {
      "id": "q001",
      "type": "single",
      "chapter": "心血管系统",
      "section": "心力衰竭",
      "difficulty": "medium",
      "question": "男性，65岁，劳力性呼吸困难3月。查体：双肺底湿啰音，心界向左下扩大。最可能的诊断是？",
      "options": [
        "A. 慢性阻塞性肺疾病",
        "B. 左心衰竭",
        "C. 肺栓塞",
        "D. 支气管哮喘",
        "E. 肺炎"
      ],
      "answer": "B",
      "explanation": "患者老年男性，劳力性呼吸困难提示心功能不全；双肺底湿啰音为肺淤血体征；心界扩大提示心脏扩大。综合考虑为左心衰竭。",
      "reference": "《内科学》第10版 p.175",
      "keywords": ["心衰", "呼吸困难", "湿啰音"]
    }
  ]
}
```

---

## 字段说明

### 题库元数据

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 题库名称 |
| `version` | string | ❌ | 版本号（如 "1.0"） |
| `description` | string | ❌ | 题库描述 |
| `tags` | string[] | ❌ | 标签（如 ["内科", "真题"]） |
| `questions` | array | ✅ | 题目列表 |

### 题目字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 唯一标识符（建议格式：`q001`, `q002`...） |
| `type` | string | ✅ | 题型（见下方说明） |
| `chapter` | string | ✅ | 章节（如"心血管系统"） |
| `section` | string | ❌ | 小节（如"心力衰竭"） |
| `difficulty` | string | ❌ | 难度：`easy`, `medium`, `hard` |
| `question` | string | ✅ | 题干 |
| `options` | string[] | ✅* | 选项（单选/多选题必填） |
| `answer` | string | ✅ | 答案（见下方说明） |
| `explanation` | string | ✅ | 解析 |
| `reference` | string | ❌ | 参考资料（如教材页码） |
| `keywords` | string[] | ❌ | 关键词（用于搜索与关联） |
| `images` | string[] | ❌ | 图片路径（相对于题库文件） |

\* `options` 字段对于单选题和多选题是必填的，对于其他题型可选。

---

## 题型说明

### 1. 单选题（`single`）

```json
{
  "type": "single",
  "question": "急性心肌梗死最常见的并发症是？",
  "options": [
    "A. 心律失常",
    "B. 心源性休克",
    "C. 心脏破裂",
    "D. 室壁瘤"
  ],
  "answer": "A"
}
```

- `options` 必填，每个选项以 `A. `, `B. ` 等开头
- `answer` 为单个字母：`"A"`, `"B"`, `"C"`, `"D"`, `"E"`

### 2. 多选题（`multiple`）

```json
{
  "type": "multiple",
  "question": "心力衰竭的常见诱因包括？",
  "options": [
    "A. 感染",
    "B. 心律失常",
    "C. 妊娠",
    "D. 过度劳累",
    "E. 饮酒"
  ],
  "answer": "ABCD"
}
```

- `answer` 为多个字母组合：`"ABC"`, `"BD"`, `"ABCDE"` 等

### 3. 判断题（`truefalse`）

```json
{
  "type": "truefalse",
  "question": "ACEI 类药物是心衰的首选治疗药物。",
  "answer": "true"
}
```

- `answer` 为 `"true"` 或 `"false"`
- 不需要 `options` 字段

### 4. 填空题（`fillblank`）

```json
{
  "type": "fillblank",
  "question": "正常成人心率为 ___ 次/分，超过 ___ 次/分为心动过速。",
  "answer": ["60-100", "100"]
}
```

- `answer` 为数组，每个元素对应一个空
- 题干中用 `___` 表示空（三个下划线）

### 5. 病例分析题（`case`）

```json
{
  "type": "case",
  "question": "患者男性，70岁，胸痛2小时...\n请回答：\n1. 最可能的诊断？\n2. 首选的检查？\n3. 治疗方案？",
  "answer": "1. 急性心肌梗死\n2. 心电图 + 心肌酶\n3. 急诊PCI或溶栓 + 双抗 + 抗凝",
  "explanation": "..."
}
```

- 题干和答案可用 `\n` 换行
- 适合主观题，答案作为参考答案展示

## 高级特性

### 1. 图片题

```json
{
  "question": "下图心电图提示？",
  "images": ["ecg_stemi.png"],
  "options": ["A. 正常心电图", "B. 急性心梗", "C. 心房颤动", "D. 束支传导阻滞"],
  "answer": "B"
}
```

- `images` 为图片文件名数组
- 图片文件需与题库 JSON 放在同一目录（或指定相对路径）

### 2. 关键词关联笔记

```json
{
  "question": "...",
  "keywords": ["心衰", "ACEI", "利尿剂"]
}
```

- KNOWLATTICE 会自动关联包含这些关键词的笔记
- 做题时可快速跳转到相关笔记复习

### 3. 难度分级

```json
{
  "difficulty": "hard"
}
```

- `easy`：基础概念题
- `medium`：临床应用题
- `hard`：复杂病例或鉴别诊断

练习时可按难度筛选。

## 批量生成题库

### 方法 1：用 AI 生成

打开教材笔记，在 AI 对话框输入：

```
/出题 数量:50 格式:json
```

AI 会生成 JSON 格式的题库，直接保存为 `.json` 文件。

### 方法 2：从 Word/Excel 转换

如果你有 Word 或 Excel 格式的题库，可以用 Python 脚本转换：

```python
import json

# 示例：从 Excel 读取题库
import pandas as pd
df = pd.read_excel('题库.xlsx')

questions = []
for _, row in df.iterrows():
    questions.append({
        "id": f"q{row['序号']:03d}",
        "type": "single",
        "chapter": row['章节'],
        "question": row['题干'],
        "options": [row['A'], row['B'], row['C'], row['D']],
        "answer": row['答案'],
        "explanation": row['解析']
    })

with open('题库.json', 'w', encoding='utf-8') as f:
    json.dump({"name": "内科学题库", "questions": questions}, f, ensure_ascii=False, indent=2)
```

## 导入与管理

### 导入题库

1. 侧边栏 → "练习" → "题库管理"
2. 点击"导入题库" → 选择 `.json` 文件
3. 导入后会显示题目数量与章节分布

### 查看与编辑

- 题库列表可查看所有已导入题库
- 点击题库名称 → "编辑" → 可修改题目（会导出回 JSON）
- 支持批量删除不需要的题目

### 合并题库

如果有多个 JSON 文件，可以手动合并：

```json
{
  "name": "内科学综合题库",
  "questions": [
    ...题库A的题目...,
    ...题库B的题目...
  ]
}
```

注意每道题的 `id` 必须唯一。

## 常见问题

**Q: 可以导入 Anki 卡片吗？**  
A: 可以，但需要先转换为 JSON 格式。参考上面的 Python 脚本，从 Anki 导出 CSV 后转换。

**Q: 题库文件可以加密吗？**  
A: 目前不支持。如果需要保护题库，建议将 JSON 文件压缩并设置密码。

**Q: 一个题库最多能有多少题？**  
A: 理论上无限制，但建议单个文件不超过 5000 题（否则加载会变慢）。

**Q: 如何分享题库？**  
A: 直接分享 `.json` 文件和图片文件夹即可。其他用户导入后可直接使用。

**Q: 能否从网页直接抓取题目？**  
A: KNOWLATTICE 本身不提供爬虫功能。你可以用 Chrome 插件或 Python 爬虫抓取后转换为 JSON。
